침출 공정 디지털 트윈

황산 침출조를 가상 공간에 세우고, 모듈 1·2·3 파이프라인이 추천한 레시피를 그대로 운전 조건으로 넣는다. 치수와 수량은 아래 띠에서 씬 그래프를 직접 세어 표시한다. Ni 95% · Co 90% 를 동시에 넘길 수 있는 원료는 드물다 — 목록의 ✓ 가 달성 가능한 원료이고, ✕ 는 허용 범위 안에 해가 없는 원료다(기본 목표 기준). 이 판정과 추천 레시피는 파이썬 모듈 3 이 계산한 값이다.

목표 달성 판정은 파이썬 모듈 3 의 결과만 싣는다 — 원료 목록의 ✓/✕ 와, 「모듈 3 추천 레시피 적용」으로 옮긴 조건의 판정이다. 슬라이더로 다른 조건을 고르면 회수율 평균 · 산 비율 · 적용 범위 거리만 계산해 보여 주고, 비율이나 적용 범위를 벗어난 경우만 거절로 표시한다(그 밖은 「참고」). 회수율 평균과 적용 범위 거리는 파이썬과 소수점 넷째 자리까지 일치하지만, 확률 제약 μ − 1.28σ ≥ 목표 에 쓰는 불확실성 σ 는 트리 앙상블이 필요해 브라우저에서 정확히 계산할 수 없기 때문이다. 임의 조건의 정확한 판정은 Streamlit 데모(docker compose up → localhost:8501)에서 본다. 액위는 황산 투입량, 액체 색은 침출 온도, 교반기는 운전 상태를 따른다.
